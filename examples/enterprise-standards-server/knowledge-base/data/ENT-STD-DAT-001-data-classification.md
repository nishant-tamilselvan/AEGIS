# Data Classification

> Sample content. Replace this knowledge base with your organization's own standards.

| Class | Examples | Handling |
| --- | --- | --- |
| public | Published reports, open data | No restrictions |
| internal | Internal procedures, non-sensitive operational data | Staff access only |
| confidential | Personal information, financial records, security data | Need-to-know access, encrypted at rest, access logged |

Every data store records the highest class of data it holds. Retention periods follow the
records schedule owned by the Data Governance Office.
